# 🚀 Mitra-Mandli – Social Media Application

Mitra-Mandli is a full-stack social media application built using the MERN stack, featuring real-time communication and interactive social features. The platform enables users to connect, share content, and communicate through chat and audio/video calls.

---

## ✨ Features

- 🔐 Authentication & Authorization (JWT, bcrypt)
- 💬 Real-time Chat (Socket.IO)
- 📞 Audio/Video Calling (WebRTC)
- 📝 Create, Edit, Delete Posts
- ❤️ Like & Comment System
- 👥 Follow / Unfollow Users
- 🔔 Real-time Notifications
- ⚡ Optimized Performance (Pagination, Indexing)

---

## 🛠 Tech Stack

### Frontend
- React.js
- Redux Toolkit
- HTML5, CSS3 / Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)

### Real-Time & Communication
- Socket.IO
- WebRTC

### Authentication & Security
- JWT (JSON Web Token)
- bcrypt
- OAuth (optional)

### Tools & Services
- Git & GitHub
- Postman
- Cloudinary (for media uploads)
